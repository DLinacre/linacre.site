# Internal portfolio curation record — 2026-11-04

## Scope and confidence

The checked-in original catalogue contained 25 projects and 77 external game entries. All 25 linked GitHub README files were retrieved where available; a README or repository existing is not a live functional audit. Browser work covered the locally served selected projects and seven local games. The 77 external game hosts and most external project deployments could not be launched from this environment. This is a provisional editorial selection, **not a comprehensive audit or a claim that excluded work is broken**. Repositories, deployments, assets and data remain intact.
