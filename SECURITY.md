# Security Policy

Thank you for helping keep **linacre.site** safe.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Instead, report the issue privately through GitHub's security advisory feature if available, or contact the repository owner directly with:

- A clear description of the problem
- Steps to reproduce
- Affected files, versions, or URLs
- Any suggested fix

## Scope

This project is provided as-is. Security reports are welcome for code, build/deployment configuration, and published GitHub Pages assets in this repository.
